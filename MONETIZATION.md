# Monetization Strategy

> Cách biến Competency Framework từ free open-source thành sản phẩm có doanh thu.

---

## Model tổng quan

```
FREE (mãi mãi)           PAID (nâng cấp)          B2B (enterprise)
│                        │                         │
├─ Tạo roadmap           ├─ Analytics dashboard    ├─ Team workspace
├─ Public share          ├─ AI roadmap generator   ├─ SSO/SAML
├─ Fork từ community     ├─ Custom domain          ├─ Advanced analytics
├─ Track tiến độ         ├─ Paid roadmap creator   ├─ Dedicated support
├─ Gamification          ├─ Priority support       ├─ SLA
└─ 3 workspaces max      └─ Unlimited workspaces   └─ Custom contract
```

---

## Tier 1: Free (Growth Engine)

**Mục đích:** Grow user base, viral loop, community.

```
Included:
    ├─ 3 workspaces cá nhân
    ├─ Tree nodes không giới hạn
    ├─ Public share link
    ├─ Fork community roadmaps
    ├─ Progress tracking + gamification
    ├─ Daily planner
    ├─ Skills matrix
    ├─ Basic certificate
    └─ Export JSON/CSV

Viral mechanics:
    → Public share = free marketing
    → Fork = content distribution
    → Certificate share = LinkedIn exposure
```

---

## Tier 2: Pro ($5-10/tháng hoặc 99-199k VND)

**Target:** Individual creator, learner nghiêm túc.

```
Pro features:
    ├─ Unlimited workspaces
    ├─ Analytics: views, forks, drop-off per node
    ├─ AI roadmap generator: mô tả topic → AI tạo tree
    ├─ Custom domain: roadmap.yourname.com
    ├─ Embed widget cho blog/website
    ├─ Advanced certificate (branded, PDF đẹp)
    ├─ Paid roadmap: set price, collect payment
    ├─ Remove "Powered by CF" branding
    └─ Priority support

Pricing:
    Monthly: 149k VND / $6
    Annual:  999k VND / $40 (50% off)
```

---

## Tier 3: Team ($20-50/tháng hoặc 499k-1.2tr VND)

**Target:** Startup, training center, school.

```
Team features (includes Pro):
    ├─ Up to 30 members
    ├─ Role-based access (owner/editor/learner)
    ├─ Team analytics: member progress, skill gap
    ├─ Bulk invite (CSV)
    ├─ Assignment: assign roadmap to members
    ├─ Manager dashboard: at-risk members alert
    ├─ Export Excel/PDF báo cáo
    └─ Slack/Discord integration

Pricing:
    20 seats:  999k VND / tháng
    50 seats: 1.99tr VND / tháng
    100 seats: 3.5tr VND / tháng
```

---

## Tier 4: Enterprise (custom pricing)

**Target:** Công ty lớn, trường đại học, chính phủ.

```
Enterprise features (includes Team):
    ├─ Unlimited seats
    ├─ SSO / SAML integration
    ├─ Custom domain + branding
    ├─ On-premise deployment option
    ├─ Advanced audit log + compliance
    ├─ SLA 99.9% uptime
    ├─ Data export / ownership guarantee
    ├─ Dedicated support + onboarding
    ├─ API access + webhooks
    └─ Custom feature development

Pricing: 5-50tr VND / tháng tùy quy mô
```

## Go-to-Market: 3 giai đoạn

### Giai đoạn 1: Open Source Traction (tháng 1-3)
```
Mục tiêu: 1000 GitHub stars, 500 active users

Actions:
    ├─ Post "Show HN: Open source roadmap.sh alternative" → Hacker News
    ├─ Post lên r/webdev, r/devops, r/opensource
    ├─ Viết bài "I built an open source Duolingo for DevOps" → Dev.to
    ├─ Post lên Facebook group "Dev Việt Nam" (300k members)
    ├─ Invite 20-50 DevOps blogger/YouTuber tạo roadmap free
    └─ Product Hunt launch

KPI: Stars, forks, Discord members
```

### Giai đoạn 2: Creator Economy (tháng 4-6)
```
Mục tiêu: 50 paid creators, 500 paid learners

Actions:
    ├─ Launch "Creator Program": early creators get Pro free 6 tháng
    ├─ Feature top roadmaps trên /discover homepage
    ├─ Creator newsletter: tips để viral roadmap
    ├─ Case study: "Thầy X kiếm được Y từ roadmap của mình"
    └─ Affiliate: creator earn 10% khi refer paid user

KPI: Creator count, learner count, GMV
```

### Giai đoạn 3: B2B Sales (tháng 7-12)
```
Mục tiêu: 10 B2B customers, 50-100tr MRR

Actions:
    ├─ Cold outreach: HR/L&D manager tại công ty tech VN
    ├─ Demo: "Bạn đang spend bao nhiêu để train nhân viên mới?"
    ├─ Pilot: 1 tháng free cho 10 nhân viên
    ├─ Case study: "Công ty X giảm 60% thời gian onboarding"
    └─ Partnership: IT training center offer platform cho học viên

KPI: B2B customers, MRR, NPS
```
